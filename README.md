# Academia GEIFEM

Plataforma de cursos online de GEIFEM Academy: catálogo de cursos, evaluaciones y cobro de matrículas.

## Qué resuelve

Permite vender y dictar cursos especializados en línea, con cobro de pagos, generación de facturas y evaluaciones por unidad.

## Stack técnico

- **Framework:** Next.js (App Router) + TypeScript
- **Base de datos:** PostgreSQL vía Drizzle ORM
- **Pagos:** ePayco
- **Facturación:** Alegra (API)
- **Autenticación:** better-auth
- **Infraestructura:** Docker / docker-compose
